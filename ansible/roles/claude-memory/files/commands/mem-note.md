---
description: ブログネタになりそうな話題を、後で辿れる軽いインデックスとしてagent-memory(mem)に記録する
---

指定された話題について、ブログのネタ候補として、後から生のチャットログ(このセッションのjsonl)を
辿れる程度の軽いインデックスだけをagent-memory(mem)に保存してください。要約や本文は書かない。
位置の手がかりだけ残します(本文の抽出は、後で別途生チャットログから直接行う前提)。

対象の話題: $ARGUMENTS

## 手順

1. 対象の話題について、日付・大まかなキーワード・話の見出し(1行程度)を含めた短い内容で
   `mem fact notes <subject> "<日付、話題の見出し、辿るための手がかり>" --desc "<短い要約>"` を実行する
   (subjectは話題を表す短いスラッグ)
2. 実行後、何を保存したか簡潔に報告する
